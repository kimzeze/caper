# Project Caper

평범한 계획에 제목을 붙여 하나의 작전으로 만드는 기록이다.

"친구랑 물로켓 만들자"를 **Caper 01 · To the Moon** 으로 부르면, 같은 일도 한 편의
작전이 된다. 계획을 세우고, 해 보고, 남긴다.

## 이름

caper(케이퍼)는 장난스럽고 대담한 일탈, 한탕을 뜻한다. 친구들을 모아 작전을 짜고
실행하는 영화 장르를 케이퍼 무비(〈오션스 일레븐〉 같은)라고 부른다.
