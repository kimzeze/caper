# Project Caper

평범한 계획에 영화 제목 같은 이름을 붙여 하나의 프로젝트로 만드는 곳이다.

"친구랑 물로켓 만들자"를 **To the Moon** 으로 부르면, 같은 일도 한 편의 영화가
된다. 포스터를 붙이고, crew를 모으고, 해 보고, 남긴다.

## 이름

caper(케이퍼)는 장난스럽고 대담한 일탈, 한탕을 뜻한다. 친구들을 모아 계획을 짜고
실행하는 영화 장르를 케이퍼 무비(〈오션스 일레븐〉 같은)라고 부른다.

## 만드는 순서

1. 모바일 웹
2. iOS 앱
3. 데스크탑 웹
